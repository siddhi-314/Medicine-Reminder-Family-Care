MEDICINE REMINDER & FAMILY CARE — NODE.JS BACKEND (NO PHP)

Included features:
- Dashboard with feature cards only; click a card to open the feature.
- Editable Profile, Family Members, Medicine Tracker, Appointments, Care Tasks, Medical Reports.
- Medicine status: Pending / Taken / Skipped, plus Medicine History.
- Dashboard Statistics, in-app Notifications and Disease Medicine search.
- Backend API built with Node.js built-in modules. No PHP, MongoDB or npm packages required.
- Records persist in data/db.json.

HOW TO RUN ON WINDOWS:
1. Install Node.js LTS if it is not already installed.
2. Extract this ZIP into a folder, e.g. Desktop\Medicine_Reminder_Family_Care.
3. Open that folder in VS Code.
4. In VS Code select Terminal > New Terminal.
5. Run: node server.js
   (or run: npm start)
6. Wait for "Family Care app running at http://localhost:3000"
7. Open http://localhost:3000 in Chrome.

IMPORTANT:
- Do not open index.html directly with file://. Start server.js first.
- Data is stored locally in data/db.json.
- This local backend is not automatically hosted by GitHub Pages. For public internet use, deploy Node.js to a Node.js hosting provider.
- Disease information is educational and does not prescribe drug names or doses.
- This is a project starter and does not include login/authentication or encrypted medical data.
